Sevora

Встраиваемый ИИ-консультант для сайтов бизнеса. Мультитенантный бэкенд, дашборд для клиентов (настройки бота, диалоги, заявки, статистика), виджет ставится одной строкой. Архитектура, код, деплой, биллинг, поддержка и общение с клиентами на мне.

Гибридный rag

dense + sparse с rrf в qdrant, reranker jina, parent-child чанкование. База знаний из обхода сайта или Google Sheets.

Маскинг персональных данных

Отдельный ner-сервис на presidio. Маскинг обратимый, сырые данные остаются в Yandex Cloud, в openai уходит только замаскированный текст.

Изоляция клиентов

Тенант определяется по api_key в middleware, каждый поиск в qdrant фильтруется по product_slug.

Биллинг по диалогам

Считаю логические диалоги, а не токены. Лимиты тарифов, уведомления на 80 и 100%, никаких списаний на временных ошибках.

Каскад моделей

Дешёвая модель на роутинг запроса, основная (gpt-5.4-mini) только на генерацию ответа. Снизил стоимость запроса.

Прод без сюрпризов

github actions с двухфазным cutover: build → integration tests → swap → smoke. sentry, vector → better stack, watchdog перезапускает упавшие сервисы.

Как я работаю с ai

claude code уже год мой основной инструмент. Работаю с дисциплиной: план до кода, узкие роли, проверка независимым ревьюером. Понимаю, где ai экономит часы, а где выдаёт мусор и нужна ручная доводка. Собрал для этого свои скиллы:

grill-me

Допрашивает план по каждой ветке решений, пока в нём не останется дыр. Любая задача со схемой БД или новым эндпоинтом идёт через него.

local-review

Независимый субагент ревьюит незакоммиченный diff. Для auth и потока персональных данных добавляется security review.

Решения фиксирую в ADR, отдельный скилл синхронизирует архитектурную документацию с кодом.
